# EpicKor Reels V2 Style Guide

Use this for new EpicKor Reels made from newly published blog posts.

## Goal

Make Reels feel tighter, funnier, and more watchable than blog-summary videos while still sending viewers toward EpicKor.com.

## Creative Shape

- Open with a contradiction, not a definition.
- Treat the first 1 second as the thumbnail and hook.
- Build around `hook -> tension -> payoff -> save cue`.
- Use conversational American English, short sentences, and quick turns.
- Avoid essay phrasing. If a sentence would look natural in a blog paragraph, shorten it for voice.

## Timing

- Target duration: 32-42 seconds.
- Use 6-8 scenes.
- Scene 1 should land the hook in under 2 seconds.
- Use exactly two motion-card inserts unless the representative explicitly approves an exception.
- Keep visual scenes moving, but avoid cutting faster than the viewer can read the caption.

## Text

- Main screen text: 3-7 words where possible.
- No paragraph cards.
- Every scene needs one clear viewer question, contrast, or payoff.
- Captions should follow phrase beats, not tiny grammar fragments.
- Keep captions out of the Instagram bottom UI zone and away from motion-card footers.

## V2 Motion Cards

Use motion cards as structure, not decoration.

Preferred card types:

- `ingredient_stack`: a stacked list that builds the idea quickly.
- `wrong_vs_right`: a split board for tourist mistake vs Korean table habit.
- `receipt_check`: a checklist-like receipt for what to save or remember.
- `tiny_rule`: one sharp rule with a small example.

Avoid:

- empty-center layouts.
- card-news PNGs as background.
- dense labels under synced speech captions.
- three or more motion cards in a normal Reel.

## Visuals

- Use food/action close-ups for food topics.
- Prefer hands, table rhythm, texture, and social context over generic product shots.
- Each visual must prove the current spoken beat.
- If a source post has strong images, start there. Add external or generated images only when the scene needs them.

## Ending

- End with a save cue, not a lecture.
- Show `epickor.com`, not a post-specific path.
- Caption CTA should be practical: `Save this before Korean BBQ night.`
