## 2. 문제점 (심각도순)

### P1. 소셜 업로드 정체 — 퍼널 상단이 막혀 있음

- 승인 완료 Reels 6개 + 카드뉴스 3배치(9캐러셀)가 전부 미스케줄 상태. 제작 속도가 업로드 속도를 크게 앞지름.
- 북극성 퍼널(Instagram → 사이트 방문 → Amazon 클릭)의 첫 단계가 사실상 멈춰 있는데, 하단(링크 감사, 트래킹, 콘텐츠)만 계속 고도화되는 불균형.
- Amazon 감사 결론 그대로 "클릭 볼륨이 병목"인데, 클릭 볼륨을 만들 소셜 자산이 창고에 쌓여 있음.
- 화/수/목 카드뉴스 + 금/토/일 Reels 리듬이 몇 주째 실제 가동되지 않으면 Instagram 계정 워밍업 전략 자체가 지연됨.
- 필요 결정: ① 어느 3-Reel 배치를 먼저 올릴지(294/296/297 vs 299/301/302), ② 296/297 폰 리뷰 완료, ③ 카드뉴스 배치 스케줄 승인. 전부 대표 결정 대기 항목.

### P2. 이미지 최적화 전면 비활성화 — SEO 사이트의 성능 리스크

- 2026-07-12 Vercel 이미지 변환 쿼터 소진(HTTP 402) 사고 대응으로 `next.config.ts`에 `images.unoptimized: true` 적용. 장애 대응으로는 옳았으나 원본이 그대로 서빙됨.
- 실측: `public/assets/images` 총 920MB, 500KB 초과 파일 429개, 최대 7.99MB(Blog 188 부산 이미지 — 하필 Agoda 파일럿 페이지).
- 영향: 모바일 LCP/Core Web Vitals 악화 → 검색 랭킹과 이탈률에 직접 타격. 유입의 대부분이 검색인 사이트에서 구조적 감점 요인.
- 근본 해결은 빌드 전 사전 최적화(원본을 1200-1600px, WebP/JPEG 200-400KB로 일괄 변환 + 신규 글 파이프라인에 용량 게이트 추가). Vercel 최적화 재활성화보다 쿼터 재발 위험이 없고 비용도 없음.

### P3. 레거시 콘텐츠 부채 — 구간 130-160대가 사이트 품질을 끌어내림

- SEO/AEO 감사(268개 기준): 평균 점수 79/100, thin content(<700단어) 117개(44%), FAQ 없음 99개, 내부링크 부족 137개(51%), 180일 초과 stale 87개.
- Critical 5개(슬러그 137/139/152/154/157): 300-400단어, H2 0개, 내부링크 0개, 어필리에이트 0개. 이런 글은 수익 기여 0이면서 사이트 전체 품질 신호를 깎음.
- Amazon 계정이 최종 심사 대기 중인 시점에 저품질 페이지 다수는 심사 리스크로도 작용 가능.
- 신규 글은 100/100인데 구형 글이 평균을 79로 끌어내리는 구조 — 신규 발행만으로는 개선 안 됨.

### P4. 미커밋 작업 유실 위험

### P5. 운영 문서 최신성 붕괴 (경미하지만 반복 비용)

## 3. 개선 기회

1. **이미지 일괄 최적화 스크립트**: `public/assets/images` 전체를 sharp로 리사이즈/재압축(원본은 별도 보관), 이후 파이프라인에 "이미지 400KB 초과 시 리뷰 실패" 게이트 추가. 429개 파일 대상, 1회성 작업으로 사이트 전체 LCP 개선.
2. **레거시 정리 스프린트**: Critical 5개부터 리라이트 또는 통합 후 301 리다이렉트(`url_mappings.json` 활용). 주당 5-10개씩 처리하면 신규 발행 리듬을 깨지 않고 3-4주 내 High 상위권 정리 가능. 리라이트 시 어필리에이트 CTA 2개 규칙이 자동 적용되므로 수익 표면적도 함께 확대.
3. **내부링크 일괄 패스**: 137개 저연결 글에 신규 고품질 글(294-305)로부터/으로의 링크 추가. 도구 없이도 감사 JSON 기반으로 반자동 처리 가능한 저비용 SEO 개선.
4. **업로드 운영 간소화**: 배치별 업로드 패키지(MP4+caption.txt / PNG+caption.txt)를 폴더 하나로 정리해 대표의 스케줄링 소요를 분 단위로 축소 — 정체의 마찰 비용 자체를 줄이는 방법.
5. **`.gitattributes` 추가 + CLAUDE.md 기본정보 표 갱신**: 10분짜리 작업으로 세션 시작 신뢰도 회복.

## 5. 종합 판단

콘텐츠 제작 파이프라인과 QA 체계는 성숙 단계에 도달했고(신규 글 100/100, Reels 2.1 게이트 스크립트화, 링크 감사 자동화), 현재 병목은 제작이 아니라 **유통(소셜 스케줄링)** 과 **기반 품질(이미지 성능, 레거시 글)** 이다. 다음 2-3주는 신규 발행 볼륨을 유지하되, 우선순위를 "새 글 추가"에서 "쌓인 자산 유통 + 사이트 기반 정비"로 옮기는 것이 북극성 퍼널(Amazon 수익) 관점에서 기대값이 가장 높다.
