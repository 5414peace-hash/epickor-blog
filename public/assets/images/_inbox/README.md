# 사진 받는 곳 (drop folder)

대표님이 보내주신 제품 사진을 **이 폴더에 파일로** 넣어주시면 제가 각 글에 설치합니다.
채팅에 붙여넣은 이미지는 제가 파일로 꺼낼 수 없어서, 이 폴더를 씁니다.

## 파일 이름은 아무렇게나 두셔도 됩니다
제가 열어보고 무엇인지 판별한 뒤 올바른 글 폴더로 옮기고, 라이선스/출처를
`public/assets/images/posts/{slug}/image-sources.md`에 기록합니다.

다만 이름에 제품명이 들어 있으면 더 빠릅니다. 예: `chaltteok-box.jpg`, `자갈치-봉지.png`
