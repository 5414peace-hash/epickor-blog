# 사진 받는 곳 (drop folder)

대표님이 찍어주신 사진을 **이 폴더에 파일로** 넣어주시면 제가 각 글에 설치합니다.
채팅에 붙여넣은 이미지는 제가 파일로 꺼낼 수 없어서, 이 폴더를 씁니다.

## 파일 이름은 아무렇게나 두셔도 됩니다

제가 열어보고 무엇인지 판별한 뒤 올바른 글 폴더로 옮기고, 출처를
`public/assets/images/posts/{slug}/image-sources.md`에 기록합니다.
이름에 제품명이 들어 있으면 더 빠릅니다. 예: `참붕어빵-박스.jpg`

기각했다. 한국에서 찍힌 게 확실한 컷은 두고두고 쓴다.

## 찍을 때

- 밝은 곳에서 정면. **포장 글자가 읽히면** 그걸로 충분하다.
- **뒷면 영양성분표·원재료명도 한 장씩** 찍어주시면 값이 크다. 그게 한국어 1차 출처가 된다.
  실제로 `412` 찰떡파이의 "땅콩 크림"이 오정보였다는 걸 **대표님이 찍어주신 라벨이 잡았고**,
  `413`의 OEM 관계(롯데 박스에 삼진식품)도 라벨의 `제조원` 필드가 증거였다.
- 각도는 여러 장이면 더 좋다. 제조사 사이트가 각도를 여러 장 주는 게 그래서 유용하다.
