## Honest labelling note

Two of these (23355660, 23355663) are **modern styled table settings, not documented jesa or
charye tables.** The captions therefore describe the individual foods — songpyeon, pears,
jujubes, dasik — which are genuinely Chuseok/ceremonial items, and deliberately avoid claiming
the photographs show an actual ancestral rite table. Presenting a styled shoot as a real charye
table would be exactly the kind of overclaim the CLAUDE.md image standard prohibits.

Pexels labels several photos in this set as "mooncakes," which is wrong — mooncakes are Chinese;
these are Korean songpyeon and dasik. The alt text and captions use the correct Korean terms.
