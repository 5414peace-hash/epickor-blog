# Blog 428 — Nongshim Postick (포스틱) — image sources

Two official Nongshim product images plus one EpicKor-made chart. The photographs are used for
**product identification** in an editorial article, per CLAUDE.md's 0차 sourcing rule (manufacturer
site first for branded packaged goods). No sponsorship or affiliation is implied or claimed.

**Manufacturer correction worth recording:** Postick is a **Nongshim (농심)** product, not Orion.
The first search pass assumed Orion because the seed arrived alongside 오감자, and the assumption
survived one full round of research before namu.wiki and Nongshim's own brand site corrected it.
The brand page is `brand.nongshim.com/potatostick/main/index` — the URL slug is `potatostick`,
not `postick`, which is why a direct guess at the path 404s.

**Why not Pexels/Commons:** neither carries packshots of specific Korean packaged products —
that category of image does not exist there. This is the case the 0차 rule was written for.

**Rejected candidates on the same page:**
- `brand/info/1623985309319.jpg` (1920x504) — the **same composition** as the 800x700 file, just a
  wider crop. Two crops of one image would not count as two images.
- `non/pro/product_S.jpg` (104x104) — too small.
- `non/eve/1766723870755.jpg`, `...1787272371129.jpg`, `...1787530559158.jpg` — 210x210 promo tiles.
- `non/pro/product.jpg` (434x434) — **a different product entirely** (굴소스 볶음면). That path is
  shared/rotating, so do not assume `non/pro/product*.jpg` belongs to the brand page that linked it.
  Opening the file is what caught this.

**Chart rendering note:** the first render put the 1989 value label directly on top of the ₩500 axis
label, and the footnote line on top of the x-axis sublabels. Both were only visible by opening the
JPEG. Fixed by widening the bottom margin and moving the first point's label *below* its dot. Same
class of bug as post 426's charts — always open the rendered file.

stock photos, so no Pexels/Unsplash photo ID applies.
