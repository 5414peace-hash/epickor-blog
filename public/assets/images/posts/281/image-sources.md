- **REMOVED 2026-08-03: `korean-dosirak-meal.jpg` (was Commons `File:Dosirak.jpg`).**
  That file is a Pixabay photo by Sharon Ang tagged only "dosirak (lunch box)"; Commons
  categorised it under Dosirak on that tag alone. The photograph itself shows
  **"Central Chidlom 7th fl"** on the tray — Central Chidlom is a department store in
  **Bangkok**. It was running as this post's ogImage and opening image with the alt
  "A Korean home-style dosirak meal", so a Thai food-court tray was what Google and every
  social share displayed for a Korean dosirak guide. Replaced with a photograph whose
  Commons description names a Korean location.
  Lesson: a Commons *category* is a user tag, not provenance. Read the pixels.
