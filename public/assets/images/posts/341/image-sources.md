# Image Sources — Blog 341 (Goblin 10th-Anniversary Reunion Trip / Jumunjin, Gangneung Filming Locations)

Hard constraint honored: **no Goblin (도깨비) drama screenshots, stills, or tvN/Studio Dragon promotional
images were used.** All three images are independently-licensed, real-world photography of the actual
locations, sourced from Wikimedia Commons. None of the Commons filenames or Pexels photo IDs below appear
in any other post's `image-sources.md` (checked via repo-wide grep before selection).

## 1. `jumunjin-harbor-boats.jpg` — HERO CANDIDATE

- **Shows:** Jumunjin Harbor, Gangneung, at golden-hour/dusk — fishing boats moored at the dock, harbor
  buildings and hillside town visible across the water. This is literally the working fishing harbor in
  Jumunjin-eup that the "Goblin bench" and seaside filming spots are located next to; it is the real place,
  not a stand-in.
- **Source URL:** https://commons.wikimedia.org/wiki/File:Korea-Gangneung-Jumunjin_Harbor-01.jpg
- **Original file:** https://upload.wikimedia.org/wikipedia/commons/b/be/Korea-Gangneung-Jumunjin_Harbor-01.jpg
- **Photographer:** Flickr user "parhessiastes" (original title "Dock Sunset," taken April 29, 2007, Canon
  EOS 350D/Kiss Digital N). Uploaded to Commons as `Korea-Gangneung-Jumunjin_Harbor-01.jpg`.
- **License:** CC BY-SA 2.0 (Creative Commons Attribution-ShareAlike 2.0 Generic) — verified live on the
  Commons file page 2026-07-30.
- **Geolocation on file page:** 37°59'56.9"N, 128°44'58.07"E — matches Jumunjin Harbor.
- **Attribution line to use in post:** "Jumunjin Harbor, Gangneung. Photo by parhessiastes / Wikimedia
  Commons, CC BY-SA 2.0."
- **Why chosen:** Directly on-topic (the actual harbor), strong hero composition (boats + reflections +
  town), verifiable license, not a drama still.
- **Processed:** resized to 1600px wide, mozjpeg q80, progressive JPEG, 211KB.

## 3. `ktx-train-seoul-station.jpg`

- **Shows:** A KTX high-speed train at a platform at Seoul Station, with an overhead "Seoul / 서울" platform
  sign visible. Used for the practical "how to get there" section — since the KTX-Gangneung line (opened
  2017 for the PyeongChang Olympics) is the standard way overseas fans reach Gangneung/Jumunjin today.
- **Source URL:** https://commons.wikimedia.org/wiki/File:KTX_in_Seoul.jpg
- **Original file:** https://upload.wikimedia.org/wikipedia/commons/4/4e/KTX_in_Seoul.jpg
- **Photographer:** Wikimedia user "Syced." Photo taken 2007-08-23; uploaded to Commons 2024-03-22.
- **License:** CC0 1.0 Universal (Public Domain Dedication) — verified live on the Commons file page
  2026-07-30.
- **Attribution line to use in post:** "A KTX train at Seoul Station. Photo by Syced / Wikimedia Commons,
  CC0."
- **Caption honesty note:** This photo is Seoul Station, not Gangneung Station — the caption must say so
  plainly (e.g., "A KTX train departing Seoul; the KTX-Gangneung line covers the Seoul-to-Gangneung leg of
  the trip in under 2 hours") rather than implying this is Gangneung. It illustrates the train/mode of
  travel, not a specific station claim.
- **Why chosen over alternatives:** Two other real KTX Commons photos (`File:KTX-Sancheon.jpg`,
  `File:KTX_gimbap-dosirak.jpg`) are already used in Blog `225` and Blog `281` respectively — confirmed via
  repo-wide grep of `image-sources.md` files before selection — so they were excluded to keep this image
  unique to Blog 341.
- **Processed:** resized to 1600px wide, mozjpeg q80, progressive JPEG, 156KB.

## Searches performed but not used

- **Pexels "Gangneung beach," "Gangneung coast," "Jumunjin harbor":** returned mostly generic East Sea /
  Korea-coast stock photos with no confirmable Jumunjin-specific location tagging — passed over in favor
  of the GPS-verified Commons photos above, which are directly and honestly captionable as the real place.
- **Buckwheat field (메밀꽃) for the Gochang angle:** Per the task brief's own caption-honesty constraint,
  a generic "buckwheat field in bloom" photo cannot be verifiably tied to the specific Goblin-associated
  Gochang farm, and hedge captions like "similar to..." are a hard-reject per this site's Blog Reference
  Image Standard. Rather than run a mis-captioned or hedged image, this angle was dropped from the final 3
  images entirely. If a future revision wants a Gochang buckwheat-field beat, it should either (a) find and
  verifiably confirm a specific licensed photo of the actual Gochang Cheongsando/buckwheat farm location,
  or (b) cover the Gochang buckwheat detail in text only, without an accompanying photo.
- **Wikimedia Commons `Category:Jumunjin-eup`:** contains exactly one file at the time of this check (the
  2020 GPS-tagged photo used as image 2 above); no other candidates existed in that category.
