# Image Sources — Blog 372 (Jokbal vs Bossam)

All four images are Wikimedia Commons files showing the exact subjects the article names. No stock
"generic Asian food" substitutes were used. Sourcing note: this is a dish comparison, not a branded
packaged product, so the 0차 manufacturer rule does not apply — Commons is the correct first stop
and it carries both dishes well.

- `jokbal-bossam-same-plate.jpg` — hero/OG.
  Source: https://commons.wikimedia.org/wiki/File:Bossam_and_jokbal.jpg (photo/366)
  License: **CC0**, Jungyeon Min. Original 2448×2240 → 1500px wide.
  Chosen because it is the comparison itself: pale boiled belly and dark braised trotter on one
  plate. Nothing else in Commons shows both dishes together in a single usable frame.

- `jokbal-market-stall.jpg` — the grandmother/market origin section.
  Source: https://commons.wikimedia.org/wiki/File:Jokbal-namdaemunmarket.jpg
  License: **CC BY-SA 3.0**, Kbarends. Original 2848×2136 → 1400px wide.
  A real Korean market stall with whole braised trotters under glass and a Korean 왕족발 sign.
  Vendors are visible; the caption names no one and the setting is a public commercial stall.

- `jokbal-soy-braised.jpg` — the braise-mechanics section.
  Source: https://commons.wikimedia.org/wiki/File:Korean_cuisine-Jokbal-01.jpg
  License: **CC BY-SA 2.0**, aka_maya via Flickr. Original 640×480 → 1200px wide.

- `bossam-set-with-kimchi.jpg` — the bossam section.
  Source: https://commons.wikimedia.org/wiki/File:Korean_cuisine-Bossam-01.jpg
  License: **CC BY-SA 2.0**, Nicole Cho (nchoz). Original 1024×768 → 1300px wide.
  Shows the set served in parts (pork, radish salad, tofu, wrappers), which is the point the
  article makes about bossam being assembled rather than seasoned.
