# Card News 192 Image Sources

## Source Strategy

- Primary source posts: `content/blog/192.md` and the already public, related Korea shopping-route post `content/blog/173.md`.
- Primary source image folders:
  - `public/assets/images/posts/192/`
  - `public/assets/images/posts/173/`
- Reason for using Blog 173 images: First-pass Blog 192 shelf/model stock photos were usable for the article but not Korea-first enough for a social carousel. Blog 173 already contains publicly verified Olive Young Myeongdong, Olive Young queue/signage, Olive Young interior shelves, and Myeongdong shopping street images that fit this carousel more directly.
- Derivative note: The carousel needs seven image cards and cannot repeat the same `image:` path. Cards 03-05 use separate intentional derivative filenames copied from the same Olive Young interior source photo, with different card copy and framing roles. This avoids same-carousel path duplication while keeping the visual identity Olive Young/K-beauty-first.
- External sourcing note: No new external photo sourcing was performed in this pass because the related public post already had stronger Korea-first Olive Young imagery and the representative asked to proceed quickly from the current production state.
