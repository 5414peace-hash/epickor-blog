# EpicKor 블로그 SEO/AEO + 아마존 어필리에이트 성장 플레이북

## 1) 목표 KPI (90일)
- 유기 검색 세션: +150%
- 블로그 → 아마존 링크 클릭률(CTR): 3~7%
- 링크 클릭 → 구매 전환율(CVR): 2~5%
- 상위 10위권 키워드 수: +50개
- 월 어필리에이트 매출: +100% 이상

## 2) 반드시 먼저 할 것 (데이터 기반 전환)
- Search Console `Pages`, `Queries` CSV를 주 1회 내보내기
- GA4에서 `view_item`(포스트 조회), `select_affiliate`(링크 클릭) 이벤트 설정
- Amazon Associates 리포트(클릭/주문/EPC)를 주차별로 보관
- 감으로 운영하지 말고, **노출↑ CTR↓ / 유입↑ 클릭↓ / 클릭↑ 구매↓**를 각각 분리해서 최적화

## 3) 콘텐츠 운영 전략
- 기존 120~140개 포스트를 “신규 확대”보다 “리라이트 + 클러스터링” 중심으로 전환
- 각 글을 검색 의도 기준으로 분류
  - 정보형: What/Why/How
  - 상업조사형: Best/Top/Review/Comparison
  - 거래형: Buy/Price/Where to buy
- 상업조사형/거래형 비중을 최소 35%까지 확대

## 4) AEO(Answer Engine Optimization) 기준
- 각 포스트에 FAQ 섹션(3~6문항) 추가
- 핵심 질문을 H2/H3에 그대로 반영
- 질문 1개당 40~80단어의 직접 답변 먼저 제시
- 필요 시 구조화 데이터(FAQPage, Article, BreadcrumbList) 추가

## 5) SEO 온페이지 체크리스트
- Title 45~65자, 핵심 키워드 앞쪽 배치
- Meta Description 110~160자, 클릭 유도 문구 포함
- 본문 700~1200단어(경쟁 난이도에 맞춰 조정)
- H2 최소 3개, 내부링크 2개 이상
- 이미지 alt 텍스트/캡션 최적화
- 구형 글(180일+)은 최신 정보 리프레시 후 재색인 요청

## 6) 수익화(어필리에이트) 최적화
- 포스트당 구매 의도 CTA 2~3개 배치 (상단 1, 본문 중간 1, 하단 1)
- 단일 상품보다 “용도별 추천 3~5개” 카드 구성
- 클릭 유도 문구 A/B 테스트
  - 예: “Check Price on Amazon” vs “See Best Deal”
- 링크가 존재하는 글에는 제휴 고지 문구를 명시
- 국가별 트래픽이 섞이면 OneLink 또는 지역별 링크 분기 도입

## 7) 측정/분석 스택
- Google Search Console: 쿼리/노출/CTR/평균순위
- Google Analytics 4: 랜딩/이탈/체류/전환경로
- 어필리에이트 대시보드: 클릭수, 주문수, 수익, EPC
- 주간 리뷰 지표
  - 상위 노출인데 CTR 낮은 페이지(메타 리라이트 대상)
  - 유입은 높은데 클릭 낮은 페이지(CTA/상품매칭 개선 대상)
  - 클릭은 높은데 구매 낮은 페이지(상품/가격대 미스매치 점검)

## 8) 실행 우선순위
1. 전체 포스트 SEO/AEO 감사 리포트 생성 (`pnpm audit:seo-aeo`)
2. `reports/seo-aeo-audit.md`의 Critical/High 포스트 25개 리라이트
3. 상업조사형 신규 클러스터 10개 발행
4. 내부링크 허브 페이지(주제별 모음) 구축
5. CTA/앵커 문구 A/B 테스트 운영
6. 2주 간격으로 감사 재실행 후 점수 추세 관리
