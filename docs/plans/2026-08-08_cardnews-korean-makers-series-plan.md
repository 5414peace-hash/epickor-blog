# 카드뉴스 기획 — "Korean Makers" 시리즈 6편 (비즈니스 딥다이브 원작)

> 상태: **대표님 승인 대기.** 승인 시 배치 1(3편)부터 제작.
> 원작 6편 전부 발행·라이브 검증 완료(2026-08-08) — 제작 전 발행 게이트 통과.

## 왜 이 6편이 카드뉴스가 되는가

여섯 편 모두 **한 문장 반전**이 이미 있다. 캐러셀 훅을 새로 발명할 필요가 없다:

| 원작 | 훅 (카드 01) | 반전의 크기 |
|---|---|---|
| 삼익악기 | "Your guitar might be Korean" | 1994년 세계 기타 절반 + 스타인웨이 $1 차 실패 |
| 도루코 | "You've been shaving with Korean blades" | DSC 10억$ 뒤의 무명 제조사 |
| 쿠쿠 | "LG quit. The subcontractor didn't." | 하청이 원청을 이긴 IMF 서사 |
| 모나미 | "A ₩300 pen crashed the servers" | 66배 한정판 2시간 완판 |
| JMW | "There is no aircraft motor" | 신화 해체 + 진짜 이야기 |
| 휴롬 | "Every slow juicer is a copy of this one" | 발명자가 카테고리를 잃는 이야기 |

인스타 재가동 전략 부합: 검증된 GSC 수요는 아니지만 **"강한 시각·소셜 잠재력" 예외 조항**에 해당하고, 대표님 직접 선정이므로 선정 요건 충족.

## 새 비주얼 시스템: `spec-sheet` (사양서/도면)

> 규칙: 배치마다 그 주제에 맞는 새 시스템. 기존 시스템(dark-black-bar, heat-scale,
> shelf-tag, station-sign)과 겹치지 않아야 한다.

제조업 시리즈라는 주제에서 직접 도출한 시스템:

- **바탕**: 밝은 그래프용지/도면 그리드 (연회색 모눈 위 화이트). 기존 다크 계열과 정반대.
- **주인공**: 제조사 공식 **흰 배경 컷아웃**을 그대로 얹는다 — 이미 확보한 자산(JMW·도루코·
  휴롬·쿠쿠 공식 팩샷)이 흰 배경이라 시스템과 물리적으로 맞물린다.
- **타이포**: 산세리프 모노톤(스펙 라벨) + 초대형 숫자 콜아웃. "50%", "₩300", "$1" 같은
  숫자가 각 카드의 시각적 주인공.
- **포인트**: 빨간 **검수 도장** 모티프 — `MADE IN KOREA` / `EST. 1955` / `VERIFIED` 스탬프.
  기업별 포인트 컬러 1색(도루코 스틸블루, 모나미 검정+3색, 쿠쿠 레드, 삼익 우드브라운,
  JMW 브론즈, 휴롬 로즈골드).
- **고정 요소**: 전 카드 `EPICKOR.COM` 워터마크, 카드 01 중앙 세이프존, `image_label` 실물 기입.
- **렌더러**: 기존 `html-to-png.py` 레이아웃으로 표현 불가 시 `render-specsheet.py` 신규
  작성(heat-scale·price-tag 전례 있음).

## 카드 구조 (7장 공통 골격)

1. **훅** — 제품 실물 + 반전 한 줄 (프로필 그리드 세이프존)
2. **"You know this"** — 독자가 아는 쪽 (DSC 광고, 에피폰 헤드스톡, LG 밥솥…)
3. **"You don't know this"** — 회사 실체 공개 (name_ko/name_en 선언)
4. **숫자 카드** — 초대형 스펙 콜아웃 1개 (50% / ₩15→₩300 / 70% / 20년 OEM…)
5. **전환점** — 부도·IMF·특허 무효·서버 다운 등 서사의 굴곡
6. **지금** — 현재 상태 한 줄 (정직한 반대 정보 포함: 휴롬 적자, 모나미 적자)
7. **CTA** — "Full story + where to buy" → epickor.com (아마존 언급은 캡션에서)

제품 카드 규칙 준수: **이름을 대는 카드의 이미지는 그 제품** (name_ko/name_en 필수 선언,
image_label에 실제 찍힌 것 기입).

## 이미지 수급 현황

| 캐러셀 | 보유 | 추가 필요 | 조달 경로 (실측 완료) |
|---|---|---|---|
| 쿠쿠 | 공식 2 | 3~4 | cuckooamerica Shopify bare-path 2200px, 다수 모델 |
| 도루코 | 공식 2 | 3~4 | dorco.co.kr /upload/flagship/ + Commons(면도날 클로즈업) |
| 휴롬 | 공식 2 | 3~4 | hurom.com Shopify `_1200x`, 전 모델 |
| JMW | 공식 2 | 3~4 | jmwkorea.com `/data/item/{id}/{MODEL}.png` (curl -k) |
| 모나미 | Commons 2 | 3~4 | Commons 추가분(4종 확인됨) + 한정판 이미지는 보도사진 불가 → 재검토 |
| 삼익 | 공식 1 + Commons 1 | 3~4 | **주의: 삼익 사이트는 유통 브랜드(깁슨) 이미지 혼재 — 자사 제조분만 사용** |

교차중복 규칙: 블로그 본문에 쓴 파일을 그대로 재사용하지 않고 **별도 크롭/변형 자산**으로
저장(`sources/` 폴더), 사유를 image-sources.md에 기록.

라이선스 참고: 제조사 공식 컷아웃의 소셜 사용은 블로그와 동일한 "제품 식별 편집 사용"
논리로 가되, 후원 암시 문구 금지 유지. 캡션에 브랜드 태그는 하지 않는다.

## 배치·일정 제안

3편 배치 규칙에 맞춰 2개 배치:

- **배치 1 (훅 강한 순)**: 삼익 → 도루코 → 쿠쿠
- **배치 2**: 모나미 → JMW → 휴롬

일정: 연속 예약 규칙(마지막 예약일 다음날부터 1일 1건, 05:00 KST).
현재 카드뉴스 8/12까지 + 릴스 8/13~15 예약됨 → **배치 1: 8/16·17·18, 배치 2: 8/19·20·21**
(릴스와 캐러셀은 다른 포맷이므로 8/13~15에 끼워넣는 선택지도 있으나, 하루 1건 원칙 유지 권장).

## 리스크 / 미결

1. **모나미 한정판 비주얼** — 한정판 실물 사진은 보도·리셀 사진뿐이라 사용 불가.
   해법: 일반 153 실물 + 숫자 카드("₩20,000 · 2시간 · 서버 다운")로 대체.
2. **삼익 이미지 함정** — 유통 브랜드 혼재. 자일러(자사 소유)와 삼익 브랜드 기타만 사용.
3. **영문 캐러셀의 국내 기업 서사** — 타깃은 해외 한국 관심층. "Korean Makers" 시리즈명으로
   묶어 그리드 정체성 부여.
