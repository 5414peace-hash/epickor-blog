# 아마존 제휴 CTA 스터디 — 무엇을 바꿀 수 있고 무엇은 못 하는가

**작성**: 2026-08-01 · **질문(대표님)**: *"노출 많은 포스팅 상위를 뽑아서, 그 안의 아마존 링크를
조금 더 클릭하고 싶게끔 만드는 작업을 해보면 어떨까. 가짜로 클릭하게 만들자는 게 아니라,
지금은 그냥 텍스트 링크뿐이니 삽입 방식을 스터디해보자."*

---

## 0. 결론 먼저

1. **정렬 기준은 노출이 아니라 클릭이다.** 노출은 수익이 되지 않는다
2. **가장 강력한 CTR 수단 두 개(제품 이미지·가격)는 우리에게 구조적으로 막혀 있다.**
   아마존 API 자격 요건을 우리가 못 채운다
3. **우리 전환율은 이미 업계의 2~3배다. 문제는 전환이 아니라 클릭 수다**
4. 그래서 할 수 있는 건 **버튼화·배치·문안**이고, 이건 실제로 유효하다

## 2. 우리가 못 하는 것 — 아마존 규정 (여기서 대부분의 아이디어가 죽는다)

일반적으로 제휴 CTR을 가장 크게 올리는 두 가지는 **제품 이미지**와 **가격 표시**다.
**둘 다 우리에겐 불가능하다.**

| 하고 싶은 것 | 규정 | 우리 상태 |
|---|---|---|
| 제품 사진 표시 | **저장 금지.** 직접 링크해야 하고 URL이 24시간 만에 만료 → **API 필요** | ❌ 불가 |
| 가격 표시 | **실시간 API 데이터만 허용.** 캐시는 최대 1시간, 조회 시각 명시 필수. 정적 가격은 위반 | ❌ 불가 |
| "정가 $30 → 할인 $20" | 위와 동일 — 실시간 데이터 없이는 위반 | ❌ 불가 |

**왜 API를 못 쓰는가**: PA-API를 대체하는 **Creators API는 직전 30일간 적격 판매 10건**을 요구한다.
우리는 **0건**이고, 계정 유지에 필요한 것도 180일 내 3건이다.

> ⚠️ **이건 그냥 "지금은 안 된다"가 아니라 위험 회피 문제다.**
> 우리 계정은 2026-07-27에 **한 번 닫혔다가 같은 날 재신청**한 상태다(`epickor-20`).
> 규정 위반은 계정을 다시 날린다. **정적 가격·저장된 제품 이미지는 절대 넣지 않는다.**

## 3. 우리 실측이 말하는 것 — 전환은 이미 훌륭하다

`docs/handoff/FACTS.md` → amazon, 2026-07-26 확인분:

```
2026-06-26 ~ 07-25 : 클릭 35 · 주문 4 · 배송 4 · $4.18 · 전환율 11.43%
```

**업계 평균이 3~5%인데 우리는 11.43%다. 2~3배다.**

FACTS의 결론을 그대로 옮기면 — **"퍼널은 잘 전환된다. 제약은 클릭 수다."**

즉 **"링크를 더 클릭하게 만든다"는 대표님의 방향은 정확히 맞는 지점을 짚었다.**
전환을 손볼 필요가 없고, 클릭만 늘리면 그대로 매출이 된다.

### 다만 규모는 정직하게 말씀드린다

한 달 아마존 클릭이 **35건**이다. 버튼화로 업계 수치(+24~30%)만큼 오른다면 **약 44건**이 되고,
11.43% 전환이면 주문이 **4건 → 5건**이 된다.

**작은 수를 곱하는 일이다.** 계정 유지 조건(180일 내 3건)에는 직접 도움이 되지만,
사업을 바꾸는 크기는 아니다. **근본 제약은 여전히 총 트래픽이고, 그건 오늘 하루 종일 한 콘텐츠 작업이다.**
이 CTA 작업은 그 위에 얹는 승수이지 대체재가 아니다.

## 4. 그래서 할 수 있는 것

### 현재 CTA의 실제 모습

`app/globals.css`의 `.affiliate-inline-cta`는 호박색 테두리 박스 안에
**문단 하나 + 문장 속 밑줄 링크**다. 독자가 **문장을 읽어야 링크를 발견한다.**

### 바꿀 것: 링크를 문장에서 꺼내 버튼으로

- **규정 안전**: 우리 CSS로 만드는 버튼이다. 아마존 로고·이미지·가격을 쓰지 않는다
- **업계 수치**: 버튼이 텍스트 링크 대비 **+24~30%** (업계 보고치이지 검증된 학술 수치는 아니다)
- **문안 원칙**: 클릭하면 무슨 일이 일어나는지 그대로 쓴다.
  가격을 암시하지 않는다(`$20에 사기` 금지). 아마존이 보증한다는 인상을 주지 않는다
- **유지할 것**: 글당 **CTA 박스 2개 상한**(대표님 규칙), 첫 CTA 근처의 제휴 고지,
  `rel="nofollow sponsored noopener noreferrer"`, 새 탭

### 측정은 이미 된다

`components/AnalyticsEvents.tsx`가 아마존 링크 클릭에 **`affiliate_amazon_click`**을 이미 발화한다.
**따라서 이 변경은 측정 가능하다.** 적용 전후 클릭 수를 비교하면 된다.

## 5. 실행 계획

1. `.affiliate-cta-button` CSS 추가 (우리 자산만 사용)
2. **상업적 의도가 높은 상위 글부터** 적용: `071` · `171` · `275` · `198` · `274`
3. 2~3주 뒤 `affiliate_amazon_click` 수를 비교한다.
   **아마존 대시보드의 클릭 수와 GA4 이벤트 수를 함께 본다** — 둘이 크게 어긋나면 계측 문제다
4. 효과가 확인되면 나머지 글로 확대. 확인되지 않으면 되돌린다

## 6. 하지 않을 것 (기록해서 재론 방지)

- ❌ 제품 이미지 삽입 — API 없이는 규정 위반
- ❌ 가격·할인율 표시 — 정적 가격은 위반이고 계정을 위험에 빠뜨린다
- ❌ CTA 박스 3개 이상 — 대표님 규칙
- ❌ 클릭을 유도하는 과장·허위 문구 — 대표님이 명시적으로 배제한 방향이고,
  전환율 11.43%는 **신뢰가 작동하고 있다는 뜻**이다. 그걸 깨면 전환이 먼저 무너진다
