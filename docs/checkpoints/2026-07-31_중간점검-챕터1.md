## 2. 이번 조사에서 내가 틀렸던 것 4가지

기록하는 이유: 개별 오류보다 **패턴**이 문제였다. 4번 다 "출처 하나 보고 멈춘 뒤 단정"했다.

| 내가 한 말 | 실제 |
|---|---|
| "크리에이트립 제휴는 6~8%" | **40%가 맞았다.** 만료된 프로모 페이지를 보고 맞는 숫자를 틀리게 고쳤다 |
| "URL 마이그레이션이 최대 레버리지" | **반증됨.** 구글 "리스크는 있고 이득은 없다". 우리 사이트에 이미 반증 사례(`/blog/074` 숫자형 8.0위 vs 키워드형 7.9위) |
| "1위는 혼자 하는 블로거" | **작성자 8명, 934편, 2013년 도메인.** 코리아타임스 출신 기고자 포함 |
| "벤치마크 대비 86.4% 미달" | **틀린 커브와 비교했다.** GSC 데이터는 GSC 기반 커브(1위=3.9%)와 비교해야 하는데 클릭스트림 커브(1위=39.8%)를 썼다. 제대로 보면 **0.363%는 기대치 이상** |

**다음 점검 때 확인할 것**: 이 패턴이 줄었는가. 단정하기 전에 "이 출처가 최신인가, 상관관계인가 인과관계인가"를 물었는가.

## 3. 경쟁 지형 — 검증된 사실

독립 표본 2회(54개 쿼리 → 53개 다른 쿼리)가 같은 결론:

| | 1차 | 독립 재검증 |
|---|---|---|
| 등장 도메인 | ~270 | **297** |
| 1회만 등장 | ~180 (67%) | **228 (77%)** |
| 최다 도메인 점유율 | 22% | **13.2%** |
| 한국 정부 사이트 | 12회 | **3개 쿼리 (5.7%)** |

**지배자가 없다. 이건 쿼리 선택의 우연이 아니라 이 시장의 성질이다.**

### 그러나 "진입 장벽이 없다"는 과장이었다
- `korea-insider.com`: 273페이지(349 아님, 오히려 줄었음), **2026-06-02부터 발행 중단**, 1년짜리 도메인 → 치고 빠지는 콘텐츠 팜. 지금 순위는 **식은 사이트의 잔상**
- **콘텐츠 팜은 10주면 순위를 살 수 있다. 유지할 수 있다는 증거는 없다.**

### 좁은 니치 지배의 실제 사례
**`90daykorean.com`이 한국어 학습 쿼리를 독점** — 어학 9개 중 **7개(78%)**, 나머지 44개 중 **0개**.
2013년 창업, "한글 90분 챌린지" 하나로 시작, 같은 버티컬 안에서만 확장, 수익은 제휴가 아니라 유료 강의.
**단, 12년 걸렸고 실명 강사진이 있고 SEO 밖에 상품이 있다.**

## 4. 결정적 갈림길 — 제품 쿼리는 두 개로 갈린다

| 쿼리 형태 | 누가 이기나 | 판정 |
|---|---|---|
| **"where to buy X"** | 소매점만 (sayweee ×5, 월마트, 타겟, 아마존). **에디토리얼 0개** | **닫혔다. 기사로는 못 이긴다** |
| **"what is X / how does it work / A vs B"** | 권위 사이트 없음. `epickor/171` **7위**, `epickor/071` **7위**, `samgak kimbap how to open`은 2014년 블로그스팟이 1위 | **열렸고 우리가 이미 그 안에 있다** |

제품 쿼리 10개에서 두 번 이상 등장한 도메인은 **아마존과 위키피디아뿐**이었다.
한국 콘텐츠 사이트 중 이 레인을 조립한 곳이 없다.

## 5. 경쟁사에게 배울 것 / 우리만 가진 것

### 우리를 이기고 있는 상대의 실체
`southkoreahallyu.com` = **런던 거주 영국인 부부 2명, 153편**(우리 309편의 절반), 2023년 여행 사진.
이삭토스트 글 **1,103단어**에 들어 있는 것:
> 2025년 6월 기준 정확한 메뉴 가격 · "키오스크에 영어 설정 있음" · "대부분 지점에 화장실 없음" ·
> "명동점 촬영 금지" · "포장지에 성경 구절" · "첫 입에 소스가 흘러내림"

**전부 가게에 서 있어야 아는 사실이다. 우리는 정의를 약속하고 저들은 숫자를 약속한다.**

### 저들이 절대 복제 못 하는 우리 자산
1. **한국어를 못 읽는다.** SKH가 "종교가 중요한 **것 같다**"고 쓴 부분 — 창업 스토리·가맹점 수·점포 추이가
   전부 한국어로 공개돼 있다. 나무위키·네이버플레이스·다나와·공정위 정보공개서·KOSIS가 저들에겐 닫혀 있다.
   **"~인 것 같다"가 우리가 같은 키워드에서 이기는 지점이다.**
2. **저들 가격은 썩는다.** "2025년 5월 마지막 방문 기준" = 오늘로 14개월 전. 다음 항공권 살 때까지 계속 낡는다.
   우리는 편의점 가격표를 오후 한 나절이면 다시 찍는다.
3. **둘 다 출처를 안 단다.** 외부 링크의 85%가 제휴 링크다.

### 이번 주에 바로 적용 가능한 기술 (자산 불필요)
| 변경 | 출처 |
|---|---|
| **`Last Updated` 표시, 발행일 숨김** (스키마엔 둘 다 유지) | Soul of Seoul |
| **제목에서 연도 스탬프 제거** — 갱신일이 신선도를 담당 | Soul of Seoul |
| **`Quick Guide` 표를 서문 직후 첫 요소로** | Soul of Seoul |
| **모든 장소 소제목에 한글 병기** — `Museum Kimchikan (뮤지엄김치간)` | 양쪽 다 |
| **주소/가는 법/영업시간 블록 + 지하철 출구 번호** | Soul of Seoul |
| **모든 가격에 날짜 스탬프** — "2026년 7월 기준 ₩2,800" | SKH |
| 메타 설명 200~260자 (**우리 120~155자 규칙과 충돌 — 규칙을 바꿔야**) | Soul of Seoul |
| **`* * * You might like – [링크] * * *`** H2 사이 삽입 | SKH |
| 아마존 CTA = **굵은 텍스트 링크 + `>`**, 절반은 검색 링크 | SKH |
| **패킹리스트 허브 1편에 아마존 링크 25개+**, 개별 글은 0~2개 | SKH |
| **아마존보다 다이소가 싸면 그렇게 말하기** (제휴 링크 바로 옆에) | SKH |

## 6. 방향 — 이번 챕터의 결론

**좁힌다: 지목해서 살 수 있는 한국 식품·일상제품을, "이게 뭐고 어떻게 쓰나 / A vs B" 형태로,
한국어 출처로 검증하고 이번 달 가격을 박아서 쓴다.**

근거:
- 우리 최고 전환 레인 (2.154%, 문화의 14배)
- SERP가 실제로 비어 있음 (제품 쿼리 10개 중 중복 도메인이 아마존·위키뿐)
- 이미 7위에 있고 위에 있는 것들이 약함
- **한국어 접근성과 현지 체류가 경쟁사가 물리적으로 못 얻는 사실을 만들어내는 유일한 레인**

구체적으로:
- **문화 설명형을 기본값으로 찍어내는 것을 중단** (118편, 0.152%, 구조적으로 스니펫에 먹힘)
- **"where to buy X" 형태로는 절대 쓰지 않는다** — 소매점이 완전히 점유
- 모든 제품 글에: 이번 달 가격 / 한글 브랜드명 / 실제 파는 곳 / **영어 사이트에 없는 한국어 출처 사실 1개** / 정직한 "이럴 땐 사지 마세요"
- 릴스 파이프라인도 같은 레인으로 (양쪽 경쟁사 다 숏폼이 없음)

## 7. 다음 점검(챕터 2) 때 확인할 것

측정 가능한 형태로만 적는다.

1. **음식-구체 레인 글 수**가 16편에서 몇 편이 됐나. 그 레인 CTR이 2.154%를 유지/개선했나
2. **문화 설명형 신규 발행이 0에 수렴했나**
3. **090/082의 노출 점유율 56.6%가 떨어졌나** — 떨어졌다면 나머지가 자란 것
4. **클릭 절대값**이 1,216에서 늘었나
   ⚠️ **노출과 CTR로 시계열 비교 금지** — 구글이 2025-05-13~2026-04 기간 노출 과다집계 버그를 인정했고
   우리 추출본이 전부 그 구간에 있다. **클릭만 비교한다**
5. **`docs/keyword-selection-playbook.md` 주간 사이클을 실제로 돌렸나**, 몇 주치 후보가 쌓였나
6. **아마존 3건 판매 조건**을 채웠나
7. **크리에이트립 법인 가입 문의**에 답이 왔나
8. **내가 단정 전에 검증하는 습관이 붙었나** (§2의 4가지 패턴)

## 8. 미결 사항 (대표님 결정 필요)

1. **문화 설명형을 어디까지 줄일까** — 완전 중단 vs 비율 상한
