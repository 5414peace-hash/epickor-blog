# EpicKor 실행계획 챕터 1 — 2026-07-31

> 짝 문서: `2026-07-31_중간점검-챕터1.md` (현재 위치 진단). 이 문서는 그 진단 위에 세운 **앞으로의 계획**이다.
> 다음 점검(챕터 2) 때 이 계획 대비 실행 여부를 확인한다.

## 1. 정체성 — 한 문장

**EpicKor는 "지목해서 살 수 있는 한국의 구체적인 것"을, 한국 현지에서 한국어 출처로 검증해,
이번 달 기준의 사실로 알려주는 영어 사이트다.**

- 우리가 파는 것: 정의가 아니라 **판단 재료** (실물, 가격, 사용법, A vs B)
- 우리의 해자: 경쟁자는 한국어를 못 읽고, 한국에 없다. 우리는 둘 다 된다
- 전략 원칙 (검증됨): 모두에게 잘 보이려 하지 않는다. **한 레인을 먼저 압도하고, 이긴 뒤 넓힌다**

## 2. 레인 선정 — 데이터가 정한 순서

| 순서 | 레인 | 근거 |
|---|---|---|
| **1차 (지금)** | **음식-구체**: 포장 과자·편의점·길거리 음식 | 우리 CTR **2.154%** (사이트 평균 6배, 문화의 14배). SERP 무주공산 확인. 이미 7위 2건 |
| 2차 (챕터 2 검증 후) | K팝 굿즈·뷰티 제품 | 각 1.071% / 0.923% — 이미 평균 이상, 같은 "제품" 문법 |
| 3차 (분기 단위) | 거래장벽 실용 가이드 ("for foreigners" + 한국 시스템) | Trazy 검증 레인. 경쟁 있지만 우리 해자 적용 가능 |

**넓히는 조건**: 1차 레인에서 신규 글 코호트 CTR ≥ 1.5%가 확인되면 2차로 확장. 안 되면 원인 규명이 먼저.

## 3. 멈추는 것 (즉시)

1. **정의형 문화 설명글 신규 발행 중단.** 118편·CTR 0.152%·구조적으로 스니펫에 먹힘.
   - 단, 문화라도 **행동/결정 프레임이면 통과** — 결혼식 하객 가이드(124)는 2.88%로 잘 된다. 기준은 주제가 아니라 쿼리 형태다.
   - 기존 문화 글은 삭제하지 않는다 (여전히 클릭 327개 유입). 키우려는 노력만 중단.
2. **"where to buy X" 프레임 금지.** 소매점이 SERP를 100% 점유 — 검증됨. "이게 뭔가 / 어떻게 먹나·쓰나 / A vs B"로만 쓴다.
3. **아저씨·SKY 클러스터에 대한 추가 투자 중단.** 노출 56.6%는 성과가 아니라 배경 소음으로 취급한다.
4. **배관 작업 우선 금지.** 계측·설정·도구는 콘텐츠 실행에서 필요가 생겼을 때만. (GSC API는 만들어둔 상태로 대기 — 대표님 5클릭은 급하지 않음)

## 4. 새 글의 표준 — "제품 글 스펙 v1"

1차 레인 신규 글은 아래 5개를 **전부** 포함해야 발행한다. 리뷰어 체크리스트에 추가.

| # | 요소 | 이유 |
|---|---|---|
| 1 | **이번 달 가격 + 날짜 스탬프** ("2026년 7월 기준 ₩2,800") | 경쟁사(런던 거주)는 물리적으로 불가능. 14개월 낡은 가격과 싸운다 |
| 2 | **한글 병기** — 브랜드/제품/장소명 (`뿌셔뿌셔`, `Museum Kimchikan (뮤지엄김치간)`) | 검색 커버리지 + 현지 활용성. 우리가 제일 쉽게 하는 것 |
| 3 | **한국어 출처 사실 1개 이상** — 영어 웹에 없는 것 (나무위키·네이버·공정위·KOSIS·브랜드 공식) | "~인 것 같다"라고 쓰는 경쟁자를 같은 키워드에서 이기는 지점 |
| 4 | **실물 디테일** — 파는 곳, 먹는 법, 출구 번호, 영업시간 등 "서 있어야 아는 것" | SKH가 1,103단어로 우릴 이기는 방법의 역적용 |
| 5 | **정직한 반대 정보** — "이럴 땐 사지 마라 / 다이소가 더 싸다" | 신뢰 = 클릭보다 비싼 자산. 제휴 링크 옆에 배치 |

**형식 표준 (템플릿 반영):**
- 서문 직후 **Quick Guide 표** (가격/어디서/맛·용도/대안)
- 신규 글은 **키워드 슬러그** (`/blog/ppushu-ppushu-guide` 형태) — 기존 글 마이그레이션은 하지 않음 (반증 완료)
- **Last Updated 표시**, 발행일은 스키마에만
- 제목에 연도 스탬프 제거 (갱신일이 신선도 담당)
- 메타 설명 **120~260자 허용**으로 규칙 변경 — 놀라운 사실을 앞에 채우고 구글이 자르게 둔다
- H2 사이 `You might like` 내부링크 디바이더

## 5. 하루의 구성 — 리듬 변경

기존: 신규 3편/일 (넓게) → **변경: 신규 2편 + 리프레시 1편/일**

- **신규 2편**: 주간 키워드 사이클에서 나온 1차 레인 후보만
- **리프레시 1편**: 기존 글에 스펙 v1 적용. **순서: 음식-구체 16편부터** (이미 이기는 레인에서 이미 순위 있는 글 — 최소 노력 최대 효과), 다음은 클릭 상위 30편
- 근거: 이기는 사이트 둘 다 리프레시 규율이 있다 (Soul of Seoul 월 50편 갱신, 발행량은 우리보다 훨씬 적음)

**주간 키워드 사이클** (`docs/keyword-selection-playbook.md` §5 — 이미 검증된 절차):
1. 네이버 자동완성/데이터랩에서 한국 신호 수집 (한국어 차익거래)
2. 구글 영문 자동완성 대조 → 격차 = 후보
3. 쿼리 형태 필터 (정의형·구매처형 탈락)
4. 수동 SERP 판정 (소매점 점유·스니펫 해결·AI오버뷰 → 탈락 / 2014년 블로그가 1위 → 채택)
5. 주간 산출물: **후보 5개 + 판정 근거** → 대표님 승인 → 집필 큐

## 6. 수익화 — 3갈래 동시 진행

| 채널 | 액션 | 상태 |
|---|---|---|
| **아마존** | 1차 레인 글이 곧 판매 견인 (제품 글=구매 의도 독자). 3건 판매 마감 관리 | 재신청 완료, 180일 시계 진행 중 |
| **Trazy 제휴** | **즉시 가입 신청** — 법인 제한 조항 없음 확인됨. 4%지만 쿠키 6개월 | 승인 대기만 남음 |
| **Creatrip 제휴** | `partner@creatrip.com` 법인 가입 문의 (최대 40%). **의료 카테고리는 의료법 리스크로 사용 안 함** | 대표님 발신 승인 필요 |

Reels/카드뉴스도 같은 레인으로 정렬 — 두 경쟁사 모두 숏폼이 없다. 8/1~3 릴스 배치 성과를 새 기준으로 측정.

## 7. 측정 — 챕터 2 판정 기준 (약 4주 후)

**클릭으로만 비교한다** (구글 노출 과다집계 버그로 노출·CTR 시계열 비교 금지 — FACTS.md).

| # | 지표 | 기준 |
|---|---|---|
| 1 | 1차 레인 신규 글 | **12편 이상** 발행 |
| 2 | 음식-구체 기존 16편 | **전부 리프레시** 완료 |
| 3 | 신규 글 코호트 CTR | **≥ 1.5%** (2차 레인 확장 조건) |
| 4 | 사이트 클릭 절대값 | 1,216 대비 증가 (신규 글은 숙성 필요 — 방향만 확인) |
| 5 | 주간 키워드 사이클 | **4주 연속 실행**, 후보 20개 축적 |
| 6 | 아마존 판매 | 1건 이상 (3건 목표의 진척) |
| 7 | Trazy/Creatrip | 가입 완료 / 회신 수령 |

챕터 2 문서는 이 표를 채우는 것으로 시작한다.

## 8. 대표님 손이 필요한 것 (이것만)

1. **Creatrip 법인 문의 메일 발신 승인** — 문안은 준비돼 있음 (§6)
2. **이 계획 자체의 승인** — 특히 ①문화 신규 중단 ②하루 구성 2+1 변경 ③메타 설명 규칙 변경
3. (급하지 않음) GSC API 5클릭, BigQuery 카드 등록 — 콘텐츠 실행과 무관하게 언제든

나머지는 전부 승인 없이 즉시 착수 가능하다.

## 요약 — 한 문단

정의를 파는 글 118편이 노출만 만들고, 실물을 파는 글 16편이 클릭을 만든다는 것이 확인됐다.
따라서: 실물 레인(음식-구체)에 신규 2편+리프레시 1편의 리듬으로 집중하고, 모든 글에
"이번 달 가격·한글 병기·한국어 출처 사실·실물 디테일·정직한 반대 정보"의 5요소를 강제하며,
주간 한국어 차익거래 사이클로 키워드를 자체 조달하고, 아마존+Trazy+Creatrip 3갈래로 수익화한다.
4주 후 챕터 2에서 신규 코호트 CTR 1.5%를 기준으로 확장 여부를 판정한다.
