# E안 — The Archive (박물관 도록) 구현 스펙

목업: `05-archive.html`

## 콘셉트 한 줄

**"블로그가 아니라 컬렉션."**
모든 글이 **소장품(specimen)** 이고, 모든 카드가 **박물관 라벨**이다.
`ACC. 346` 같은 유물번호, 제작사/재료/수치를 나열하는 스펙 테이블,
넉넉한 여백, 헤어라인 액자.

이게 창의적인 이유: 우리는 실제로 **313편을 큐레이션한 컬렉션**을 갖고 있는데,
지금 UI는 그걸 "최신순 목록"으로만 보여준다. E안은 **축적 그 자체를 자산으로**
표현한다 — 신규 매체가 절대 흉내낼 수 없는 것.

## 디자인 토큰

```css
:root{
  --paper:#F4F1EC;   /* 갤러리 벽 */
  --card:#FCFBF9;
  --ink:#1A1917;
  --mute:#8A8478;
  --line:#D9D3C7;    /* 헤어라인 */
  --accent:#7A2E22;  /* 청자시대 산화철 적색 — 채도 낮은 한국 전통색 */
}
```
**강조색이 채도 낮은 벽돌색**인 게 포인트. A안의 선명한 red와 정반대 방향으로
"오래 축적된 것"의 인상을 만든다.

## 타이포그래피

| 역할 | 서체 |
|---|---|
| 디스플레이 | **Fraunces** 300/900 (가변 `opsz`) — 300과 900을 한 문장에 섞어 씀 |
| 본문·UI | **Inter** 400/500 |
| 라벨·수치 | **IBM Plex Mono** 400/500 |
| 한글 | **Noto Serif KR** 400/700 |

`Korea, catalogued` 처럼 **한 제목 안에서 300 ↔ 900을 교차**시키는 게 이 안의 서명.
가변폰트 `opsz`를 크기별로 조절(제목 144, 로고 96).

## 시그니처 디바이스

1. **유물번호 `.acc`** — `ACC. 346 · FOOD & SHOPPING`. 슬러그 번호를 그대로 씀
   (우리 슬러그가 숫자라 **데이터 변경 없이** 성립한다).
2. **스펙 테이블 `.spec`** — 118px 라벨 컬럼 + 값. `MAKER / BASE / HEAT / PRICE / SOURCE`.
   `lib/ramyun.ts`·`lib/convenience-store.ts` 필드가 그대로 들어간다.
3. **액자 `.frame`** — 1px 라인 + 26px 흰 여백(패스파르투). 사진이 작품이 된다.
4. **드롭캡** — 본문 첫 글자 Fraunces 900, 62px, accent색.
5. **컬렉션 통계** — `313 ITEMS CATALOGUED / AUG 2026 LAST ACCESSION`.
   축적을 첫 화면에 숫자로.

## 리스크와 완화

- **차가움/거리감** — 여행·음식의 즐거움이 죽을 수 있음. 완화: 사진을 크게,
  카피는 지금처럼 구어체 유지(레이아웃만 격식).
- **여백이 많아 스크롤 길어짐** — 모바일에서 여백 30% 축소 필요(목업 반영).
- **CTA 약함** — 밑줄 링크는 클릭률 손해 가능. 제휴 CTA만 A안식 버튼 허용하는
  예외 규칙 권장.
- 슬러그 번호 노출이 SEO에 영향 없음(표시용 텍스트일 뿐, URL 불변).
