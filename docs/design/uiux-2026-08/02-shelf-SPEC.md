# B안 — Paper Shelf (매대) 구현 스펙

목업: `02-shelf.html`

## 콘셉트 한 줄

**"인스타 카드뉴스의 세계관을 웹으로."**
2026-08에 확립한 세 카드뉴스 시스템(Heat Scale 종이·Shelf Tag 가격표·Station Sign)의
공통 DNA — 종이 바탕, 잉크 보더, 하드 오프셋 섀도, 모노 ₩가격, 옐로 플래시 — 를
사이트 전체 언어로 승격한다. IG에서 넘어온 사람이 **같은 브랜드 세계**에 착지한다.

## 디자인 토큰

```css
:root{
  --paper:  #F5F2EA;   /* 페이지 바탕 (카드뉴스 종이색 계열) */
  --card:   #FFFFFF;   /* 태그 카드 */
  --ink:    #171512;   /* 보더 3px·텍스트 */
  --mute:   #6E6A61;
  --red:    #D6151B;   /* 가격·CTA (카드뉴스 Shelf Tag와 동일) */
  --flash:  #FFD400;   /* 행사 플래시 (동일) */
  --cool:   #2F6F5B;   /* NOT SPICY 등 보조 판정색 (동일) */
  --shadow:    9px  9px 0 rgba(23,21,18,.13);
  --shadow-lg: 13px 13px 0 rgba(23,21,18,.15);
}
```

## 타이포그래피

| 역할 | 서체 |
|---|---|
| 디스플레이 | **Archivo Black** (+ Noto Sans KR 900) — 전부 대문자 |
| UI·본문 | **Archivo** 500/700 (+ Noto Sans KR) |
| 데이터 | **IBM Plex Mono** 500–700 — 가격·영수증·바코드 캡션 |

**제품 카드는 한글 먼저 크게** (`삼각김밥` 21px 900 → `SAMGAK GIMBAP` 12px 캡스) —
2026-08-03 카드뉴스에서 대표님이 확정한 순서를 웹에도 동일 적용.

## 시그니처 디바이스

1. **태그 카드 `.prod`** — 3px 잉크 보더 + 하드 섀도, 하단 점선 위 `₩가격`(red mono 19px)
   + 우측 모노 노트(`PULL 1·2·3`, `570 SHU`). 호버 시 -3px 이동(섀도 커짐) — 물리적 카드감.
2. **영수증 `.receipt`** — 히어로의 품목/합계 3행. `TOTAL — NO CARD MINIMUM ₩3,000` 처럼
   **후크 자체가 영수증**이 되는 장치. 표도 `table.receipt`(모노, 점선 행)로 통일.
3. **옐로 플래시 `.flash`** — `PRICES CHECKED AUG 2026`, `100 MILLION SOLD`.
   잉크 2px 보더 필수(카드뉴스와 동일 문법).
4. **바코드 `.barcode`** — CSS repeating-gradient, 장식용. 카드 발치·아티클 시트 말미.
   아무것도 인코딩하지 않음(카드뉴스 규칙 승계).
5. **통로 라벨 `.aisle`** — `A-1 / ON THE SHELF NOW` — 섹션 헤더가 매대 통로 표지.

## 컴포넌트 매핑

| 화면 요소 | 목업 클래스 | 실제 코드 대상 |
|---|---|---|
| 헤더(칩 내비) | `header` `nav.main` | `app/layout.tsx` — 내비를 보더 칩 버튼으로, 로고는 `EPICKOR` + 빨간 `.COM` 칩 |
| 히어로 태그카드 | `.tagcard` | `app/page.tsx` hero — 사진과 카드 분리, 영수증 블록 신규 |
| 제품 그리드 | `.grid .prod` | 홈 신규 섹션 + `/convenience-store` 가격표를 카드화 |
| 가이드 셀프 | `.shelfrow .shelf` | 홈 가이드 타일 + `/guides` — 잉크 반전(다크 카드) |
| 아티클 시트 | `.sheet` | `app/blog/[slug]` — 본문을 보더+섀도 "종이 시트"에 담음 |
| CTA | `.ctabox` | `.affiliate-inline-cta` — 옐로 바탕+잉크 버튼 |
| 표 | `table.receipt` | `.blog-content table` 스킨 |

## 리스크와 완화

- **장문 가독**: 본문 시트 내부는 Archivo가 아니라 시스템 산세리프 유지 검토(목업은 Archivo).
- **구형 글 300편 소급**: 표피(시트·칩·표)만 자동 적용되고 본문 톤은 그대로라 실측 필요 —
  파일럿으로 최근 10편 + 허브 3종 먼저.
- **소음 관리**: 플래시는 페이지당 최대 2개, 하드 섀도는 카드에만(텍스트 블록 금지).

## 구현 순서

1. 토큰+폰트 (반나절) → 2. 헤더/푸터 (반나절) → 3. 허브·제품 표면(가장 어울리는 곳부터) (1일)
→ 4. 홈 (1일) → 5. 아티클 시트 + 소급 검수 (1.5일)
