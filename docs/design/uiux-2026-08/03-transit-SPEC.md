# C안 — Night Transit (심야 노선도) 구현 스펙

목업: `03-transit.html`

## 콘셉트 한 줄

**"서울의 밤을 지하철 사인 시스템으로 읽는다."**
다크 크롬 + 서울교통공사 공식 노선색을 **기능적으로** 쓴다 — 섹션마다 색이 다르던
현 사이트의 본능을 버리는 대신, 와이파인딩 규칙으로 합법화한 안.
**본문은 밝은 시트에 남긴다** — 밤은 크롬의 것, 낮은 글의 것.

## 디자인 토큰

```css
:root{
  --night:#14171B; --panel:#1C2025; --panel2:#222731;
  --text:#F2F4F6; --mute:rgba(242,244,246,.6); --hair:rgba(242,244,246,.14);
  /* 노선색 = 섹션색 (서울교통공사 공식값) */
  --l1:#0052A4;   /* TRAVEL   */
  --l2:#00A84D;   /* GUIDES   */
  --lred:#D6151B; /* FOOD (하우스 레드) */
  --l8:#E6186C;   /* BEAUTY   */
  --l5:#996CAC;   /* CULTURE  */
  --l6:#CD7C2F;   /* BUSINESS */
}
```

**색 규칙**: 노선색은 ① 내비 점 ② 카드 상단 3px 스트라이프 ③ 원형 번호에만.
텍스트·버튼·배경엔 금지(판독성). 헤더 상단 5px `lineband` 그라디언트가 브랜드 마크.

## 시그니처 디바이스

1. **역명판 `.plate`** — 히어로. 사진 위 그라디언트, 노선 원형 번호 + `을지로` 한글 46px 900
   → 로마자 캡스 → 하단 스트립(`TIME IT TAKES — AN EVENING · STAY? WORKABLE`).
   `lib/seoul.ts`가 이미 역·호선·소요시간을 들고 있어 **데이터가 그대로 UI가 된다.**
2. **원형 노선번호 `.roundel`** — 실제 호선 숫자(2·3·6호선). 승강장에 서 본 독자는
   색으로 먼저 읽는다.
3. **출발 전광판 `.depart .board`** — 모노 캡스 + 노랑 점멸 `● NOW BOARDING` —
   검증 문구(`PRICES RE-CHECKED THIS MONTH`)를 전광판 언어로.
4. **리더 시트 `.sheet`** — 다크 안의 밝은 본문. 상단 5px 노선색 톱라인이 섹션 표시.
   다크 장문 가독 리스크를 구조적으로 제거하는 장치.

## 리스크와 완화

- **음식 사진이 다크에서 손해** → 카드 이미지에 배경 무관 풀강도 노출(딤 금지), 시트 안은 라이트.
- **"앱 같다" 인상** → 본문 영역 세리프 도입 검토 여지.
- **소급 리스크 최대** — 313편 전부 시트 래핑 QA 필요. 파일럿: `/seoul` 허브 + 동네 글 12편.
- 다크/라이트 경계(시트 진입)에서 눈부심 — 시트 배경을 순백이 아닌 `#FCFCFA`로(반영됨).

→ 4. 리더 시트 (1일) → 5. 홈 (1일) → 6. 전편 QA (1일+)
