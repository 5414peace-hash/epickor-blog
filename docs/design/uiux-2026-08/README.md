## 이유

**1위 A The Ledger.**
- 전략 정합: 실행계획 챕터 1의 정체성("이번 달 기준의 사실") 그 자체를 UI 장치로 만든 안.
  검증 칩·날짜·모노 가격이 크롬에 박힌다 → 제휴 CTA 신뢰까지 같이 오른다.
- 리스크 최소: 라이트 유지, 구조 변경 최소(토큰+스킨 중심)라 313편 소급 비용이 가장 낮다.
- 현 사이트 2대 질환(색 소음·타이포 무주인)을 가장 직접적으로 치료.

**4위 B Paper Shelf.** IG 퍼널 일관성과 제품 레인 정합은 최고. 다만 전면 적용 시
장문·비제품 글(문화/여행)에서 톤 과잉. → **권고: A를 베이스로 채택하고, B의
가격태그·영수증 DNA를 제품/허브 표면의 컴포넌트로 이식**하는 하이브리드.

**5위 C Night Transit.** 가장 기억에 남지만 소급 리스크 최대. `/seoul` 허브와
카드뉴스 Station Sign의 **서브브랜드**로 보존 — 역명판 히어로는 A 채택 후에도
`/seoul`에 부분 이식 가능.

**2위 D Stamped (신규).** A가 *신문의 권위*로 신뢰를 만든다면 D는 **사람의 손자국**으로 만든다 —
"기관이 검증했다"가 아니라 "내가 가서 봤다". 도장에 `WALKED IT`이라 쓸 수 있는 건 이 안뿐이고,
한글 손글씨 주석은 경쟁 영어 매체가 흉내낼 수 없다. **단독 채택도 가능한 수준** — A의 조용함이
걸리면 D를 베이스로 뒤집는 선택지가 유효하다. 리스크는 절제 실패 시의 장난스러움.

**3위 E The Archive (신규).** 우리는 313편을 큐레이션한 컬렉션인데 지금 UI는 "최신순 목록"으로만
보여준다. **축적 자체를 자산으로** 만드는 유일한 안이고, 슬러그가 숫자라 `ACC. 346`이 데이터 변경
없이 성립한다. 리스크는 차가움(여행·음식의 즐거움 감소).

## 최종 하이브리드 권고

A안 베이스 + ① **D의 도장**으로 A의 검증 칩 교체(A의 유일한 약점인 "조용함"을 정확히 보완)
② **E의 유물번호·스펙 테이블**을 허브/제품 글에 ③ **B의 가격태그**를 편의점·라면 허브에,
**C의 역명판**을 `/seoul`에.

## 공통 안전 원칙 (대표님 지시)

- URL·라우팅·헤딩 구조·스키마·본문 마크다운 **무변경**. 표피(CSS 토큰·컴포넌트)만.
- 폰트는 next/font 셀프호스트(외부 요청 0).
- 단계별 배포: 토큰 → 헤더/푸터 → 아티클 크롬 → 홈 → 허브. 각 단계 롤백 가능.
