## 권고 순위와 이유

**1위 A The Ledger.**
- 전략 정합: 실행계획 챕터 1의 정체성("이번 달 기준의 사실") 그 자체를 UI 장치로 만든 안.
  검증 칩·날짜·모노 가격이 크롬에 박힌다 → 제휴 CTA 신뢰까지 같이 오른다.
- 리스크 최소: 라이트 유지, 구조 변경 최소(토큰+스킨 중심)라 313편 소급 비용이 가장 낮다.
- 현 사이트 2대 질환(색 소음·타이포 무주인)을 가장 직접적으로 치료.

**2위 B Paper Shelf.** IG 퍼널 일관성과 제품 레인 정합은 최고. 다만 전면 적용 시
장문·비제품 글(문화/여행)에서 톤 과잉. → **권고: A를 베이스로 채택하고, B의
가격태그·영수증 DNA를 제품/허브 표면의 컴포넌트로 이식**하는 하이브리드.

**3위 C Night Transit.** 가장 기억에 남지만 소급 리스크 최대. `/seoul` 허브와
카드뉴스 Station Sign의 **서브브랜드**로 보존 — 역명판 히어로는 A 채택 후에도
`/seoul`에 부분 이식 가능.

## 공통 안전 원칙 (대표님 지시)

- URL·라우팅·헤딩 구조·스키마·본문 마크다운 **무변경**. 표피(CSS 토큰·컴포넌트)만.
- 폰트는 next/font 셀프호스트(외부 요청 0).
- 단계별 배포: 토큰 → 헤더/푸터 → 아티클 크롬 → 홈 → 허브. 각 단계 롤백 가능.
