# 사진 보강 계획 — 세로 이미지 위주 글에 가로 사진 얹기

작성 2026-08-02. 여러 세션에 걸쳐 진행하는 작업이라 **진행 상태를 이 파일에서 관리한다.**
배치를 끝낼 때마다 아래 체크박스를 갱신할 것.

## 전제 (대표님 판정, 재론 금지)

- **세로 1080x1920 이미지는 그대로 둔다.** 릴스용 텍스트/썸네일로 의도 제작된 것이다.
  가로 크롭 일괄 작업도 하지 않는다. 허용된 것은 **가로 사진을 한두 장 얹는 것**뿐이다.
- 2026-08-01에 교체한 `136`/`155`/`156`은 비율 때문이 아니라 **초상 변형과 캡션 불일치**가 사유였다.
  비율 이슈와 혼동하지 말 것.

## 대상 선정 기준

`세로 1장 이상 + 가로 1장 이하`인 글 = **67편**. 여기서 티어를 나눈다.

## 티어

### C — 손대지 않는다 (10편)

실존 인물·방송·IP라 **자유 라이선스 사진이 존재하지 않는다.** 무료 스톡을 넣으면 글이 말하는
대상이 아닌 사진을 넣게 되고, 그것이 정확히 `156`에서 고친 문제다. 역설적이지만 **이 글들은
현재의 릴스 프레임이 구할 수 있는 최선의 이미지다** — 실제로 그 인물·작품을 담고 있다.

`030` 최민식 / `031` 셀럽 인스타 / `043` 장원영 / `044` BTS 뷔 / `052` K팝 생일카페 /
`058` 여름 K팝 / `067` 웹툰→드라마 / `070` 넷플릭스 드라마 / `181` 웹툰 / `310` 국민 MC

### B — 개념 설명글, 실제 한국 일상 장면 **1장씩** (9편)

직접 피사체가 없는 개념글이다. 대표님 지시: **기존 이미지는 유지하고 실제 장면 1장을 추가**한다.

- **캡션 규칙**: 그 장면이 무엇인지만 말하고 **개념을 단정하지 않는다.**
  (O) "서울 지하철의 노약자석" / (X) "눈치를 보여주는 장면"
- **식별 가능한 인물 얼굴은 피한다.** 실존 인물을 '아저씨'나 '꼰대'로 규정하는 셈이 되기 때문이다.
  뒷모습·군중·빈 공간·사물 위주로 고른다.

`035` 눈치 / `049` 헬조선 / `056` 한국 개관 / `072` 강도문화 / `080` 속담 /
`085` K-브랜드 / `090` 아저씨 / `319` 정 / `330` 꼰대

### A — 실물이 존재한다, 가로 사진 1~2장 (48편)

음식·시장·시설·장소·사물. 커먼즈+Pexels로 조달 가능. 2026-08-02에 6편(`126` `128` `133`
`145` `153` `082`)을 이 방식으로 처리했고 전부 찾았다.

## 매 배치 게이트 (오늘 실제로 걸린 것들)

1. **중복 검사는 선택 시점에.** `node scripts/audit-image-uniqueness.mjs --check-id {photoId}`.
   초안을 다 쓴 뒤에 하면 히어로를 다시 만들어야 한다. 2026-08-02 배치에서 Pexels `19271596`과
   `26732085`가 여기서 걸려 교체했다.
2. **Korea-first.** 같은 배치에서 냉면 후보 하나가 **베이징 촬영본**이라 탈락했다. 파일명과 제목만
   보고 믿지 말고 설명·촬영지를 확인한다.
3. **캡션이 사진보다 더 주장하지 않는다.** 그 섹션이 다루는 대상을 실제로 담고 있어야 하고,
   아니면 무엇을 담고 있는지 정직하게 쓴다. "~를 대신하여", "실제 ~는 아니지만" 같은
   변명형 캡션은 하드 리젝이다.
4. **`image-sources.md`에 출처·라이선스·촬영자 기록.** 탈락시킨 후보와 사유도 남긴다.
5. **용량**: 장당 150~250KB 목표, 포스트 폴더 합계 1MB 초과 시 줄인다.
6. **리뷰어 재실행** 후 커밋. `node .claude/skills/reviewer/scripts/review-post.mjs --draft content/blog/{slug}.md`

## 조달 소스 순서

1. **Wikimedia Commons** — `gsrnamespace=6`, contact 포함 UA, 라이선스는 CC0/CC BY/PD만.
   **한국어 제품·장소명으로도 검색할 것** (영문 서술구로는 안 나오는 것이 나온다).
2. **Pexels** — 랜드스케이프 필터. 한국 소재는 "seoul", "korean" 조합으로.
3. **공유마당** (`gongu.copyright.or.kr`) — 전용 Chrome 프로필이 스크래치패드에 있고
   **쿠키가 살아 있어 재로그인 없이 재사용 가능**하다. 절차: `python /tmp/gongu_live.py`로
   프로필을 CDP 9223에 띄우고(런처 프로세스를 죽이면 브라우저도 닫힌다),
   이후 스크립트는 `connect_over_cdp`로 붙는다. 폼 선택자: `#wrtTy`(사진) `#licenseCd`(CCL) `#searchWrd`.
   본 이미지는 `wrtFileImageView` + `wrtSn={sn}&`, `ctx.request.get()`으로 받는다.
   **라이선스 필터**: 본문에 `비영리`/`변경금지`가 있으면 버린다.
   **⚠ 검색이 제목·컬렉션명 매칭이라 주제와 무관한 것이 대량으로 섞인다** — 2026-08-02 실측:
   `서울대학교` → **서울과학기술대학교**(다른 학교), `반려동물` → **광둥성 동물**(중국),
   `편의점` → 선유도공원·잠실운동장. **건수는 신호가 아니다. 반드시 이미지를 열어볼 것.**
4. **KTO Photo Gallery** (KOGL 1유형, 하루 20장) — **대표님 가입 필요.** 커먼즈·공유마당에 없는
   한국 소재(서울대 캠퍼스, 망원시장, 삼각김밥 실물)가 여기 있을 가능성이 남아 있다.
