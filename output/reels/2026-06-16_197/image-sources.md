# Reels 197 Image Sources - v5

- Search strategy: whole-Reel Boryeong Mud Festival context first; no isolated scene-keyword sourcing for S5-S7.
- Official 280x350 festival images: reference-only, not selectable due low resolution.
- Pexels generic transport, generic shoes, generic beach crowds: removed from selectable dashboard.
- Flickr public-feed candidates: not used as selectable visuals because license was not verified in this pass.
- Wikimedia Commons sources used: Boryeong Mud Festival main/2008/2011 categories and source-post Commons/Flickr records.
- Quality gate: every selectable source passes long edge >=1000 and short edge >=800 before 1080x1920 crop.
- Scene 2 replacement: all five S2 candidates are real Boryeong Mud Festival photos with visible mud/participants, not balloons, signs, food stalls, or graphic-like location placeholders.
- S2 source set: new Commons downloads `commons-boryeong-mud-festival-girls.jpg` and `commons-korea-boryeong-mud-festival-27.jpg`, existing Commons `mud-festival-22`, `mud-festival-24`, and `Korea-Boryeong-13`.
- Optional Commons fetches for `Mud_Fest_2008.jpg` and `Korea-Boryeong_Mud_Festival-01.jpg` hit temporary Wikimedia 429 and were not used.
- Crop control: the static dashboard lets the representative drag the visible 9:16 crop window and lock crop coordinates into the copy string/localStorage before final production.
- Duplicate gate: v5 source pool uses 30 unique file hashes and no repeated selectable sourceFamily.
